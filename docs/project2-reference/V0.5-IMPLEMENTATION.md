# AI Marketing OS V0.5 — Runtime Persistence

## Implemented

- Prisma singleton and tenant access guard.
- Database-backed context loading for company profile, documents, CRM, marketing, analytics, and finance.
- AgentRun persistence before and after execution.
- Production prompt lookup from the database.
- Agent registry/seed ID alignment.
- Tool adapter layer for read-only tenant-scoped tools.
- Production-mode requirement for authenticated user context.
- Version bumped to 0.5.0.

## Partially Implemented

- AI provider remains Mock by default.
- Authentication/session enforcement is not yet implemented.
- Vector similarity retrieval is not yet implemented; document metadata retrieval exists.
- External tools (web search, publishing, notifications, billing writes) remain blocked until explicit adapters and approvals are added.

# RBAC V1

| Role | Scope |
|---|---|
| OWNER | Full organization + billing + business command center |
| ADMIN | Organization administration, users, clients |
| MARKETING_MANAGER | Strategy, content, campaigns, reports |
| SALES_MANAGER | CRM, pipeline, proposals |
| STAFF | Assigned operational work |
| CLIENT_USER | Client portal, approvals, reports |
| VIEWER | Read-only access |

All authorization must be checked server-side. UI hiding is not a security boundary.

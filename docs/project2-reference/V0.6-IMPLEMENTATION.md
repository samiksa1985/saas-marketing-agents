# AI Marketing OS — V0.6

## Implemented
- Cookie-based server sessions backed by PostgreSQL.
- Registration and login with Node.js `scrypt` password hashing.
- Tenant-bound session validation for AI execution and RAG endpoints.
- OpenAI Responses API provider using server-side `OPENAI_API_KEY`.
- OpenAI Embeddings API integration using `text-embedding-3-small` by default.
- pgvector schema/migration with a 1536-dimensional vector column and HNSW cosine index.
- Tenant-scoped document chunk ingestion and semantic search.
- Knowledge retrieval can be included automatically in agent context when `knowledgeQuery` is supplied.
- Authentication UI at `/auth`.

## Partially implemented
- File parsing currently supports the ingestion API's supplied text payload; PDF/DOCX/XLSX/PPTX parsing is deferred to the document-processing worker.
- Structured Outputs are validated through Zod after generation; strict JSON Schema response formatting will be added when agent schemas are centralized.
- Production rate limiting and session revocation UI are not yet complete.

## Environment
Set:
- DATABASE_URL
- OPENAI_API_KEY
- OPENAI_MODEL (default: gpt-5.6)
- OPENAI_EMBEDDING_MODEL (default: text-embedding-3-small)

Apply the Prisma migration with `prisma migrate deploy` in a real PostgreSQL environment where the pgvector extension is available.

## Security notes
- API keys never reach the browser.
- Agent and RAG requests are tenant-scoped.
- AI-generated information remains subject to human review/approval.

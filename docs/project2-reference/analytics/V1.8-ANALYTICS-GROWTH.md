# V1.8 — Analytics, Attribution & Growth Intelligence

## Purpose
Connect marketing activity to leads, opportunities, customers and revenue.

## Core flow
Campaign → Touchpoint → Lead → Opportunity → Customer → Revenue

## Capabilities
- campaign and channel performance
- funnel analytics
- multi-touch attribution foundation
- lead-to-revenue attribution
- CAC / LTV / ROAS / conversion
- cohort metrics
- experiment analytics
- marketing health score
- growth recommendations
- executive reporting
- forecasting foundation

## Principles
- tenant scoped
- source-aware metrics
- immutable event ledger for attribution
- derived metrics are reproducible
- no invented metrics when source data is missing
- financial metrics distinguish actual, estimated and modeled values

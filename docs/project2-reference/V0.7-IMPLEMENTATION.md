# V0.7 — Golden Workflow

Implemented:
- Persisted WorkflowRun and WorkflowStep models.
- Authenticated end-to-end workflow execution.
- New Client Campaign workflow with dependency-aware step context.
- Onboarding persistence endpoint.
- Structured-output support in the OpenAI Responses provider.
- Workflow status and failure persistence.

Golden workflow:
Client onboarding → Business Intelligence → Market Research → Marketing Strategy → Campaign → Creative → Content → SEO → QA → Client Approval gate → Measurement → Optimization → CFO Review.

## Important
Client approval is represented as a workflow gate. The current synchronous executor stops at the gate if the agent returns BLOCKED; a production queue/approval UI will resume the workflow in a later phase.

## API
POST `/api/onboarding` — persist the authenticated organization's company profile.
POST `/api/workflows/new-client-campaign` — run the authenticated organization's golden workflow.

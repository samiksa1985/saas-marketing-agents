# AI Marketing OS — Workflow Catalog V1

## WF-01 New Client Activation
Signup → onboarding → company intelligence → knowledge ingestion → initial strategy → approval → activation

## WF-02 Marketing Strategy Build
Business intelligence + market research + historical analytics → strategist → strategy version → approval

## WF-03 Campaign Launch
Goal → strategy → campaign → creative → content → landing page → QA → approvals → launch adapter → measurement

## WF-04 Content Production
Brief → strategy context → content → creative → QA → internal approval → client approval → schedule/publish

## WF-05 Lead Qualification
Lead created → enrichment → scoring → qualification → opportunity creation → sales next-best-action

## WF-06 Sales Follow-up
Opportunity → risk/priority analysis → recommended next action → task → optional approved external communication

## WF-07 Customer Health
Usage + results + support/activity + billing → health score → risk/upsell recommendations → account task

## WF-08 Monthly Business Review
Revenue + costs + clients + campaigns + pipeline → analytics → CFO → business mentor → executive report

## WF-09 Renewal
Renewal window → health → profitability → results → renewal recommendation → proposal → approval → renewal

## WF-10 Upsell
Customer health + usage + results + product fit → opportunity → offer → proposal → approval → expansion

## WF-11 Marketing Optimization
Campaign metrics → attribution → analytics agent → experiment proposal → approval → experiment → measurement

## WF-12 Document Intelligence
Upload → security check → extraction → normalization → chunking → embeddings → index → retrieval → citations

## WF-13 Automation Execution
Trigger → conditions → AI decision → action → wait → condition → next action → audit

## WF-14 Weekly CEO Brief
Sales + finance + delivery + customer health + AI cost → business mentor → priorities → lessons

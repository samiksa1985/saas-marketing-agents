# AI Marketing OS V1.2 — Core Implementation

## Scope

V1.2 implements the core required to support the full product without adding new product scope:

- Database-backed organization tenancy
- Authentication/session APIs
- Organization membership
- RBAC permission checks
- Plan subscriptions
- Plan/organization entitlements
- Usage counter foundation
- Versioned `/api/v1` foundation
- Authenticated organization/me/dashboard endpoints

## New endpoints

- `GET /api/v1/me`
- `GET /api/v1/organization`
- `PATCH /api/v1/organization`
- `GET /api/v1/entitlements`
- `GET /api/v1/dashboard`

## Registration behavior

Registration now creates:

1. Organization
2. Owner user
3. Owner membership
4. Starter trial subscription when the Starter plan exists

## Entitlement model

Plan entitlements are the default. Organization-level entitlements override plan values. Usage limits are tracked by organization and monthly period.

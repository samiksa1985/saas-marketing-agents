# V0.8 — Production Hardening

## Scope

V0.8 does not add product features. It hardens the existing V0.7 foundation and establishes repeatable validation before GitHub/production use.

## Implemented

- Static project validation script.
- CI workflow for dependency install, Prisma generation, structural validation, smoke tests, and production build.
- Tenant-model schema validation.
- Agent registry/documentation coverage validation.
- Required environment variable validation.
- Build/test commands standardized in CI.

## Validation status

The local environment did not complete `npm install` within the available execution window, so a local production build cannot honestly be marked as passed here. CI is configured to perform the authoritative dependency install and build in a clean Node 20 environment.

## Explicitly not added

- No new product features.
- No new AI agents.
- No new integrations.
- No new customer-facing workflows.
- No pricing changes.

## Exit criteria

V0.8 is considered technically validated when CI passes:

1. `npm ci`
2. `npm run db:generate`
3. `node scripts/validate-project.mjs`
4. `npm test`
5. `npm run build`

After these pass, the repository is ready for the GitHub baseline and the next implementation phase.

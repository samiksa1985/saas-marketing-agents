# Marketing execution specification

Marketing execution packages model campaigns, content, creative, and SEO as canonical artifacts with validation, quality rules, evidence, approval bindings, and workflow handoffs. Drafts are not publication. Publish readiness requires approved artifacts and remains behind Tool Gateway for any external effect.

Market intelligence, strategy, customer success, CFO, analytics, automation, and Business Mentor supply evidence-bound inputs or advisory outcomes. The mentor is advisory-only. Current product routes expose composition states for campaigns/content/creative/SEO, not an external publishing console. CRM, publishing, research, analytics ingestion, and provider adapters remain external work.

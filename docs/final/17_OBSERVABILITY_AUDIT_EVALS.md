# Observability, audit, and evaluations

The repository records workflow audit events, state transitions, task leases, artifact/handoff references, approval decisions, governance audit data, evidence IDs, confidence, and model/provider usage/cost metadata where the runtime exposes it. Tests exercise audit append behavior, redaction boundaries, workflow transitions, agent evidence, and entitlement consumption.

The API and worker now share a portable structured JSON logger with request correlation and sensitive-field redaction. The API offers process-local HTTP histograms and security/workflow/provider outcome counters through an opt-in, bearer-protected Prometheus text endpoint. Portable dashboard and alert definitions and an operator runbook are in `infra/observability/` and `docs/production/OBSERVABILITY_RUNBOOK.md`. These are code-level contracts: no collector, trace backend, dashboard service, alert destination, retention job, or target-environment verification is claimed live. Retention and tenant-specific evaluation datasets remain deployment/governance work.
